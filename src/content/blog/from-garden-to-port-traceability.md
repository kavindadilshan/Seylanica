**Traceability means being able to follow a cinnamon lot from where it was grown, through processing and testing, to the container it shipped in, using a lot number that appears at every step.** It underpins food safety, recall readiness, authenticity and every origin claim a brand makes.

## The traceability chain

| Stage | What is recorded |
| --- | --- |
| Intake | Grower or collection point, date, weight, intake checks |
| Lot creation | Unique lot number assigned |
| Grading and sorting | Grade, quantities, by-products |
| Drying and storage | Conditions, location |
| Milling (powder) | Batch, equipment, date |
| Testing | COA linked to lot number |
| Packing | Lot number on every bag or carton |
| Export | Lot numbers on packing list, invoice, certificates |

## Why it matters

- **Food safety:** if a problem is found, you can identify exactly which product is affected.
- **Recalls:** targeted withdrawals instead of blanket recalls.
- **Authenticity:** a documented chain makes substitution with cassia much harder. See [cinnamon adulteration](/blog/cinnamon-adulteration-detection).
- **Origin claims:** brands can back up statements such as "grown in Sri Lanka". See [where Ceylon cinnamon grows](/blog/where-ceylon-cinnamon-grows-sri-lanka).
- **Regulation:** EU food law requires one-step-back, one-step-forward traceability.

## How Seylanica handles it

At Seylanica, lot numbers are assigned at intake, and sourcing origin is displayed only from lot paperwork, never from static marketing copy. Each lot's COA, packing list and export documents carry the same lot number. See the [Quality & Origin page](/quality).

## What buyers should check

- Lot numbers on **bags, COA, packing list and invoice** match.
- The supplier can show **intake records** for a lot on request.
- **Retained samples** are kept per lot.
- A **mock trace** can be completed quickly: pick a lot and ask the supplier to trace it backward and forward.

## Traceability on retail packs

Brands should print a lot code on each pack, linked internally to the export lot. Some add QR codes to share origin information with consumers. See [labelling requirements](/blog/cinnamon-label-requirements-eu-us).

## Summary

Traceability turns a supply chain into evidence. Insist on consistent lot numbers, test the system with a mock trace, and carry lot codes through to your own packs. [Request a sample COA](/buyer-hub) to see how our lot documentation works.
